# EasyMini image digitization

User-supplied image titled EasyMini-v3.0 9174 flight 6; 1501 x 767 pixels

Manual visual centreline anchors; linear interpolation between anchors. Approximate image-digitized values, not original telemetry.

The image was supplied directly in chat. The raster attachment was not available as a local file; coordinates were manually read from the displayed image. No claim of pixel-exact automated extraction or original telemetry. Calibration and every chosen pixel are retained in easymini-trace.json. The CSV is a 0.25 s linear resampling of these anchors, not independent measurements. Approximate extrema: height 5860 m, speed 930 m/s, acceleration +450 / -280 m/s². Values at curve overlaps, the jagged height section around 3–13 s and extrema have visual-reading uncertainty. Do not use for precise derivatives, dynamics validation or flight-event attribution.

User confirmed this is an actual launch recording. No launch date or association with the separate April 1 test-launch video was supplied.
