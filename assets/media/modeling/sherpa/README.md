## Modeling distinctions

README.txt “Revision 2 priorities,” prioritized_trajectory_study.json and dynamics_validation.json distinguish: a propagated Earth-Moon circular restricted three-body halo/manifold candidate; direct and return analytic Earth two-body conics with idealized kinematic patches to a representative halo state. The manifold is not targeted to GTO; it does not validate the original PDR time or cost. Direct/return conics omit lunar gravity, use an assumed reference phase and cover coast only. The return endpoint is tangent at a 120 km boundary, not a descending entry corridor or recovery solution. Public prose retains model type and scope without presenting comparative cost/time performance claims.

README.txt “Fluid model”: assumed quasi-static lumped tank states with visual particle tracers. Geometry, control equipment, tank volumes and conditions include added assumptions. Slosh, bubbles, transient line flow and full microgravity fluid physics are outside that model. Public copy describes a schematic cutaway and interfaces, not tested refueling performance. Operating recipes and source tables are omitted.
