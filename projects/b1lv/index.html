Hardware preparation

Detail B · Drawings to parts
  1. 01 · Organize the pipingCross-checked the P&IDs against the Hardware Utilization List and flagged missing parts.
  2. 02 · Set up cleaningWith MOCAT unavailable, designated lab sessions won on cost, cleanliness control and practicality.
  3. 03 · Check the cleaningWater-break tests showed all five component sets needed another cycle.
  4. 04 · Compare pressurant layoutsTwo concepts weighed on safety, leakage, compactness, ergonomics and simplicity.

I kept meeting notes, design-change records and the Hardware Utilization List, and co-authored the piping FMEA. The team recommended visual valve-position indicators so operators could confirm actuation.

System & setup

Detail C · See the path before the data

The replica isolates the oxidizer piping from the rest of the vehicle. Valves, fittings and instrumentation tie each measurement to its physical path.

Water-flow testing

Detail D · Trace discrepancies to the setup

Issue 1 · Leak

A visible leak forced a reset and repeat of run 3. Comparisons with earlier measurements stayed uncertain.

Issue 2 · Mass accounting

A collection-container error needed a calculation correction.

I co-authored the post-test report on the leak investigation, retest and correction.

Tank model

Detail E · Simulation vs. hand calcs

The tank-analysis report compared SolidWorks fatigue analysis with hand calculations.

Its conclusions depend on the loading assumptions, so the assumptions are stated with the result.

Lessons

Make assumptions visible

General notes

  1. Understand the measurement path.
  2. Examine uncertainty before using a nominal prediction.
  3. Record the change while the context is fresh.
