Six flight modes in simulation

Learned residual vs DLQR

Negative result · 200 held-out cells

A PPO policy trained for 3 million steps added position corrections on top of the DLQR controller, using only the onboard estimate as input. On 200 held-out Mode 3 cells on the measured camera cone, every run with the policy failed.

24 / 200plain DLQR passes · 12.0%, 95% Wilson interval 8.2 to 17.2%
0 / 200DLQR plus PPO residual passes · 0%, 95% interval 0 to 1.9%
24 → 0baseline successes the policy broke, with none fixed

With the residual set to zero, the evaluation harness reproduces plain DLQR exactly, so the drop comes from the policy. Both arms fly the same paired cells with residual accelerations of 0.05 to 0.20 m/s².
