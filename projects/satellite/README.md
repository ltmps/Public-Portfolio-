# SPACEJAM source chronology

The Berkeley/Honeywell capstone ran from August 2023 to May 2024. The numerical comparison displayed on the page comes from continued simulation verification in 2026, rather than a measured capstone hardware result. The public page uses timeless simulation-result wording; this document retains the chronology.

Previously verified comparison: 6.476082397 to 1.003707818 arcseconds vector RMS (84.5013% reduction), rounded publicly to 6.48 to 1.00 and 84.5%. Measurement window: final 60 seconds of a 120-second simulation, prescribed wheel/cryocooler disturbance torque, sensor noise disabled, simplified flexible model. Quantity is spacecraft attitude error. The inherited initializer credits W. Soh. These conditions remain on the public page.

The homepage capstone entry describes modeling, mitigation assessment and communication; it does not assign the later numerical comparison to the 2023–2024 project period.

Homepage cleanup also consolidates the separate CPP Liquid Rocket Lab entry into Bronco 1's existing Propellant Feed Systems entry, preserving P&ID and cryogenic-system scope. The removed standalone entry listed June–July 2022, which is within the retained broader 2022–2023 project period.
